Exhibit A — The Blank Page Finding

Most significant finding in this evaluation

A blank page is not always read as blank.

Document B contains three pages that are genuinely blank — confirmed by manually inspecting the scanned image, not inferred. All three should produce empty OCR output. Two did. One didn't.

Fail — page 2
OCR fabricated ~30 words of meaningless text from scan noise, on both the clean and degraded versions of this blank page.
"3.०० 7  Rene enc  en  Spe ow ०7०३० Be ee en..."
Pass — page 4
Correctly returned empty output on both versions.
Pass — page 6
Correctly returned empty output on both versions.

Why this matters: a pipeline that only checks "did OCR return something" would silently accept fabricated content from page 2 while correctly handling pages 4 and 6. Text-similarity metrics alone cannot catch a false-positive detection on blank input — a dedicated empty-input test is required.

Overall: 70.0% of critical fields matched exactly, unchanged between clean and degraded images. Numeric/ID fields — khasra numbers, registration numbers, dates — are the consistent weak point across all three documents, while names, areas, and locations are reliably correct. This is a materially more useful finding than a single blended accuracy number, since it identifies exactly where a downstream system would need a human safety net.

Methodology, in brief

  • Tool under test: Tesseract OCR 5.3.4 with Hindi + English language support — a free, open-source engine, chosen for reproducibility.
  • Ground truth: every page hand-verified against the source; for the two born-digital PDFs, extracted text was cross-checked against the rendered image after a duplication bug was found and fixed; the scanned document was transcribed entirely by hand.
  • Degradation: rotation, reduced contrast, blur, noise, and JPEG compression applied together to simulate a realistic poor-quality scan.
  • Suspicious-token check: 937 OCR output tokens flagged as having no plausible relationship to the source text — reported as candidates for human review, not confirmed fabrications, since most trace back to ordinary character misreads rather than invented content.
